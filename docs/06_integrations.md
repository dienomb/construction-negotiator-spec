# Integrations

## Current Integrations

### Gmail

**What it enables for the user**  
The user can send RFQs, follow-ups, counter-offers, and final confirmations through their normal email identity while keeping supplier conversations connected to the buying workflow. This lets them manage negotiations without constantly switching between tools.

### Outlook

**What it enables for the user**  
The user gets the same day-to-day negotiation workflow if they work from Microsoft email. Supplier conversations stay tied to the project and negotiation record, making it easier to track activity, review responses, and keep a complete commercial history.

### Excel

**What it enables for the user**  
The user can create RFQ sheets, import supplier quotes from spreadsheets, and export comparison or deal summaries in a format that is already familiar to most construction teams. This is especially valuable when suppliers still reply with quote tables, bid sheets, or manually updated pricing files.

## Future Integrations

### Procore

**What it enables for the user**  
Project and package context could flow in more easily, and agreed supplier outcomes could be carried into project records without duplicate data entry. This would reduce manual handoff between buying and project delivery.

### Sage

**What it enables for the user**  
Once a deal is agreed, the commercial outcome could flow into financial records more smoothly, reducing rekeying of supplier, pricing, and payment information.

### WhatsApp

**What it enables for the user**  
The user could manage supplier conversations that happen outside formal email, which is common in construction. This would help keep commercial decisions and quote changes visible even when suppliers prefer fast mobile communication.

### DocuSign

**What it enables for the user**  
The user could move from verbal or email agreement into formal sign-off faster, helping close deals cleanly and keeping acceptance records tied to the negotiated terms.

## Suggested Additions

- Add cloud file storage integrations so drawings, scope documents, and supplier attachments stay linked to each negotiation.
- Add calendar integration for quote deadlines, follow-up reminders, and supplier callback scheduling.
- Add accounting or purchasing handoff exports so final terms can move into downstream workflows with less manual copying.
- Add contact syncing so supplier contact details remain current across negotiation activity.
- Add messaging channel preferences by supplier so the user can choose the best communication route for each relationship.
